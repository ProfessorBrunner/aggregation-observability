# Region test, amended plan v2 (supersedes the test design in region_test_plan.md; written before rerunning)

**Why amended.** The v1 test placed a single moment vector in the hull, which forced the two orders' agreement masses into one number. For datasets that fail QQ, that merge moves them outside the hull, so v1 conflated QQ failure (which rejects every reciprocal class, classical included) with the projective-only constraint. v1 also calibrated with 60 bootstrap draws, too few for 73 tests.

**Data.** Dzhafarov–Zhang–Kujala S1, 73 datasets, six moments each; cells reconstructed as in v1 (verified: dataset 69 reproduces the DZK in-text table to four decimals, joint P(yes,yes) = 0.3987).

**Sample sizes.** Recovered per dataset from the S1 QQ χ² column, which is the G statistic of Wang et al. SI Eq. S2 computed from counts. With equal halves n per order, χ² = 2n[KL(d₁‖d̄) + KL(d₂‖d̄)] where d₁, d₂ are the two disagreement masses and d̄ their mean, so n = χ²/(2[KL₁+KL₂]). Where |d₁ − d₂| < 0.002 the recovery is unstable (four-decimal rounding); those datasets take the median recovered n of their source group (Pew, Gallup, other). Check: dataset 69 must recover n ≈ 500 (DZK state N = 500); Pew values should fall in DZK's stated per-order range 125–927.

**Statistic.** For each dataset, with expected counts from proportions × n:
- ℓ_QQ: maximum log-likelihood over all pairs of tables satisfying QQ. By Theorem 3(a) this is the classical reciprocal-mixture class. Closed form: common agreement mass s = (a₁ + a₂)/2 at equal n; within each order agreement cells rescaled by s/a and disagreement cells by (1−s)/(1−a).
- ℓ_P: maximum log-likelihood over tables generated by moment vectors in conv 𝒮 (two-dimensional projective mixtures). Cells are linear in the moment vector and the log-likelihood is concave, so this is a convex program; solved by Frank–Wolfe with the linear oracle over a dense sample of 𝒮. The sample uses pure states only, since for fixed frames the image is linear in the Bloch vector h and conv 𝒮 is generated by |h| = 1.
- Λ = 2(ℓ_QQ − ℓ_P) ≥ 0. QQ failure enters ℓ_QQ and ℓ_P alike and cancels; Λ measures only the projective-specific constraint.

**Validation before use.** (i) A synthetic projective population at n = 500 gives Λ near 0. (ii) The interior counterexample (0.90, 0.10, 0.99, 0.01, 0.01, 0.99) at n = 500 gives large Λ.

**Calibration.** Datasets with Λ below 10⁻⁶ are inside the class at the maximum-likelihood point and are not tested further (p = 1). For each dataset with Λ > 0: parametric bootstrap from the fitted projective mixture at the recovered n, refitting both classes per replicate; B = 200 first; if the estimated p < 0.05, extend to B = 2000. p = (1 + #{Λ* ≥ Λ})/(B + 1).

**Decision rule and kill rule.** Bonferroni over 73 datasets at 0.05 (p < 0.000685). A dataset is reported outside the projective class only if it passes that threshold. If none does, the aggregate test returns no verdict. If some do, the heterogeneous two-dimensional projective class is rejected for those datasets and not otherwise. The QQ test is reported separately from the S1 column and plays no part in Λ.

**Not done.** Any statement about individuals; any subgroup analysis (that needs microdata).
